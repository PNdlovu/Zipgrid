## Canvas

### 1. Customer Segments

| Segment | Description | Priority |
|---------|-------------|----------|
| **Homeowners (UK)** | EV owners with home charger (Level 1 or Level 2), want smart management, passive income from sharing | 🔴 Primary |
| **Small Businesses — F&B** | Cafés, restaurants, pubs with parking — drive dwell-time spend by offering EV charging | 🔴 Primary |
| **Small Businesses — Fitness/Leisure** | Gyms, leisure centres — charging as a membership differentiator | 🔴 Primary |
| **Landlords & Property Managers** | Residential and commercial landlords monetising parking with EV bays | 🟡 Secondary |
| **EV Drivers (Peer-to-Peer)** | Drivers seeking affordable, reservable charging at private homes and businesses | 🔴 Primary |
| **Installers & Technicians** | OZEV-certified EV charger installers offering services via marketplace | 🟡 Secondary |
| **Hardware Vendors** | Charger manufacturers and EV accessory retailers selling via marketplace | 🟡 Secondary |
| **Fleet Operators** | SMB fleets (delivery, trades, taxis) managing 5–50 EVs | 🟢 Phase 2 |
| **Energy Utilities** | Octopus Energy, EDF, Eon — interested in grid demand data and smart charging partnerships | 🟢 Phase 3 |
| **Local Councils** | Community-owned car parks, EV infrastructure grants | 🟢 Phase 3 |

---

### 2. Value Propositions

| For | Value Proposition |
|-----|------------------|
| **Homeowners** | Turn your idle home charger into £50–£300/month passive income. Smart scheduling charges your own EV at the cheapest tariff rate automatically. Voice control means zero friction. |
| **SMBs** | Drive EV-owning customers into your venue. Simple dashboard shows revenue, utilisation, and peak hours. No IT team needed. |
| **EV Drivers** | Find, reserve, and pay for charging at homes and businesses near you — cheaper than public networks, with guaranteed availability and real-time session control. |
| **Installers** | Reach homeowners and SMBs actively looking for certified installation, maintenance, and repairs. Verified badge builds trust. |
| **Hardware Vendors** | Sell chargers, cables, solar panels, and accessories to an audience already in the buying mindset. |
| **All Hosts** | Platform-backed £1M liability insurance, automated weekly payouts, and full session visibility — no admin overhead. |

### 5. Revenue Streams

| Stream | Model | Rate | Phase |
|--------|-------|------|-------|
| **P2P transaction commission** | % of every driver charge on host's charger | 10–15% of session value | 🔴 Now |
| **Homeowner Premium subscription** | Monthly for voice + agentic automation features | £5–£10/month | 🔴 Now |
| **SMB Starter subscription** | Up to 5 chargers, analytics dashboard | £25/month | 🔴 Now |
| **SMB Growth subscription** | Up to 20 chargers + marketplace perks | £50/month | 🔴 Now |
| **SMB Pro subscription** | Fleet tools, AI optimisation, API access | £100/month | 🟡 Phase 2 |
| **Marketplace commission** | % on hardware + services sold via marketplace | 5–10% GMV | 🟡 Phase 2 |
| **Featured / sponsored listings** | Promoted placement in marketplace search | CPC or flat monthly | 🟡 Phase 2 |
| **Idle / overstay fees** | Per-minute penalty after session ends | Platform retains 30% | 🔴 Now |
| **Enterprise contracts** | Fleet + utility data partnerships | Negotiated | 🟢 Phase 3 |
| **Anonymised grid data** | Aggregated demand insights for utilities | B2B licensing | 🟢 Phase 3 |
| **Carbon credits** | Verified EV session offsets | Per-session rider | 🟢 Phase 4 |
