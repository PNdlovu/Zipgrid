## 1. Why This Exists

Traditional forums are dying for one reason: posts sit unanswered. Someone asks "my charger stopped at 3am" and gets a reply eighteen months later from someone with the same problem. That is not a community — it is a graveyard.

Zipgrid's community solves this with one rule:

> **Every post gets a response in seconds. No exceptions.**

The AI agent monitors every new post and replies immediately. Humans then add depth, experience, and local knowledge. The result is a living, responsive community that makes EV life easier — which is the entire point.

The community is not an add-on. It is the trust layer of the platform. When a driver has a problem, they need an answer immediately. When a homeowner is not sure if their charger setup is safe, they need reassurance from peers. When a new EV owner is confused about tariffs, they need a plain-English explanation in seconds, not months.

This is how Zipgrid becomes the EV hub — not just the EV app.

## 3. Community Sections

### Section 1 — Ask & Answer Hub

The main community space. Users ask questions, AI answers immediately, humans add experience.

```
FLOW:
User posts question
         │
         ▼
AI Community Agent (< 3 seconds):
  Reads question → searches knowledge base via RAG
  → Generates plain-English response
  → Tags relevant: charger brand, tariff, region, topic
  → Marks as "AI answered — humans add below"
         │
         ▼
Human community members:
  Can upvote AI answer, add their own, or correct AI
  → "Verified by community" badge when 3+ upvotes
         │
         ▼
Expert layer (installers, tariff advisors):
  Can add "Expert answer" badge responses
  → Automatically highlighted above standard replies
```

**Sample questions the community handles:**
- "My EO charger shows a red light — is that bad?"
- "Is Octopus Agile worth it for someone who charges overnight?"
- "Can I leave my car plugged in all night on smart charging?"
- "How much can I actually earn renting my driveway charger?"
- "What do I need to tell my home insurer about my charger?"
- "Best charger for a small café with 4 parking spaces?"

The highest-priority community channel. For drivers who are stranded or in a critical situation.

**Trigger:** User posts in Emergency Help OR activates Emergency Charging Mode (2.1 PRD Module K) → automatically creates a community post

**Flow:**

```
         │
         ▼ < 5 seconds
AI Emergency Agent:
  "I can see you're at Tesco Clapham. Here's what to try right now:
   1. Press the charger reset button (usually on the left side)
   2. If that fails, unplug and replug the cable firmly
   3. If still nothing: there are 2 Zipgrid chargers 0.4 miles away
      at Sarah's driveway — I can book you in immediately.
   Shall I book the nearest available charger?"
         │
         ▼
Community layer:
  Nearby users / hosts notified: "Driver needs help 0.4 miles from you"
  → Hosts can open their listing for emergency access immediately
         │
         ▼

```

**Emergency Help moderation:** Posts stay at the top until marked resolved. AI follows up after 30 minutes if no resolution confirmed.

## 4. Voice Posting

Voice posting is available on every community input field — ask a question, post a story, write a reply.

### Technical Stack
- **Primary:** Web Speech API (browser-native, **free**, audio never leaves device)
- **Fallback:** OpenAI Whisper API (higher accuracy for strong accents, noisy environments)
- **Same infrastructure** as `2.10-voice-navigation-system.md` — zero additional cost

### Voice Posting Flow

```
User taps mic button on community input
         │
         ▼
Browser microphone activates (permission already granted from voice nav setup)
Waveform animation shows listening state
         │
         ▼
User speaks: "My charger stopped mid-session this morning.
              It was an EO Charging unit. The app showed a fault
              but now it's working again. Is this normal?"
         │
         ▼
Web Speech API transcribes in real-time (words appear as user speaks)
         │
         ▼
Preview screen:
  "My charger stopped mid-session this morning.
   It was an EO Charging unit. The app showed a fault
   but now it's working again. Is this normal?"

  [Edit]  [Post]  [Re-record]
         │
User taps Post
         │
         ▼
AI Community Agent responds in < 3 seconds
```

### Voice Replies

Users can also reply by voice — tap the mic on any reply field. This makes the community feel like a real conversation, not a slow-moving text thread.

### Accessibility Impact

Voice posting transforms community access for:
- Users with motor impairments (cannot type easily)
- Older users unfamiliar with typing on mobile
- Drivers who want to post while stationary (eyes on charger, not screen)
- Non-native English speakers (speaking is faster than composing written text)

**WCAG compliance:** Voice input does not replace text — it supplements it. Text input is always available alongside voice.

## 5. AI Moderation System

### Three-Layer Moderation

```
Layer 1: Automatic (real-time, before post is published)
  → Runs on every post and reply before it appears
  → Checks: spam patterns, offensive language, misinformation triggers,
             personal information exposure (phone numbers, addresses)
  → Decision: PUBLISH / HOLD_FOR_REVIEW / AUTO_REJECT
  → Time: < 500ms

Layer 2: AI monitoring (after publication, continuous)
  → AI reads post in context of thread
  → Flags: misleading technical advice, potential safety risk,
             coordinated spam patterns, harassment
  → Decision: FLAG_FOR_HUMAN / APPLY_WARNING_LABEL / AUTO_REMOVE
  → Human moderator reviews flagged posts within 4 hours

Layer 3: Human moderation (for escalations and edge cases)
  → All AI flags reviewed by human moderator
  → Appeals process: users can contest a removal
  → Final decision always logged in audit trail
```

### Moderation Language Rules

The AI moderator enforces these specifically for Zipgrid's convenience-first voice:

```
REMOVE immediately:
  - Personal attacks on other users
  - Deliberate misinformation about EV safety (e.g., "EVs spontaneously combust")
  - Competitor spam (paid promotion of other platforms)
  - Personal information (phone numbers, home addresses)
  - Hate speech or discriminatory content

ADD WARNING LABEL (not removed — just flagged):
  - Outdated technical information (e.g., advice about discontinued charger models)
  - Unverified health/safety claims
  - Advice that contradicts platform documentation

ALLOW but CORRECT:
  - Minor technical inaccuracies → AI adds a correction note below the post
    Example: "Good tip! Just to add: Octopus Agile rates are half-hourly,
               not hourly — so you get even more granular savings."
```

### Spam Prevention

```
Rate limiting: Max 5 posts per hour per user (soft limit — triggers review)
Account age: New accounts (< 7 days) posts go to review queue
Link detection: URLs in posts flagged automatically for human review
Pattern matching: Duplicate posts, copied content, AI-generated spam detected
Bot detection: Cloudflare Turnstile applied at community post submission
```

## 6. AI Community Agent — Behaviour Guide

The AI Community Agent is always present in every thread. Its personality and behaviour must match the Zipgrid brand.

### Personality
- **Warm, helpful neighbour** — not a corporate FAQ bot
- **Specific, not generic** — uses the user's actual details when available (vehicle, charger brand, location)
- **Honest about uncertainty** — "I'm not 100% sure — but here's what I'd try..."
- **Handoff-aware** — knows when to escalate: "This sounds like it needs an engineer — shall I find you one?"

### Response Template (internal guidance — not shown to users)

```
1. Acknowledge the situation (1 sentence, human tone)
2. Give the most actionable immediate step (plain English, no jargon)
3. Give context if useful (1–2 sentences max)
4. Offer next step (book a session, book an installer, find a charger)
5. Invite community input: "Has anyone else experienced this?"
```

### Examples

**Question:** "My Zappi shows a red light — is it broken?"

**AI Response:**
> "That red light usually means the charger has paused because it detected an issue with the power supply. Don't panic — this happens occasionally and often clears itself.
>
> First step: press the reset button on the front of the unit and wait 30 seconds. If it goes green, you're good.
>
> If it stays red after a reset, it could be a wiring issue that needs a quick check from a certified engineer. I can find one near you if you need — just say the word.
>
> Has anyone else had a Zappi red light recently? 👇"

**Question:** "Is it worth switching to Octopus Agile?"

**AI Response:**
> "For most EV owners who charge overnight, yes — Octopus Agile can cut your charging costs by 40–60% compared to a standard tariff.
>
> The key: you need to let Zipgrid schedule your charging automatically. It picks the cheapest half-hour slots each night, usually between 2am and 6am.
>
> Quick check: how many miles do you drive a week? That'll tell us how much you'd actually save.
>
> Anyone on Agile here — what's your experience? 👇"

## 9. Launch Strategy (Seeding the Community)

A new community with zero posts is worse than no community. Launch seeding plan:

- AI populates each thread with 2–3 seed questions to spark discussion
- 10 early-adopter hosts recruited to be founding community members

**At launch:**
- All 2,000 waitlist members invited to community with a specific task: "Share your EV setup in Stories"

- AI responds to every single post personally (no generic replies)

**Month 1–3:**
- Weekly "Community Spotlight" in the email digest (best post of the week)
- Monthly "Top Contributor" recognition (most helpful answers, most upvoted stories)

## 11. Web Speech API — Cost Confirmation

**Cost: Free. Always.**

Web Speech API is part of the HTML5 specification. It is built into:
- Google Chrome (all versions)
- Microsoft Edge (all versions)
- Safari 14.1+ (iOS and macOS)
- All Chromium-based browsers

**How it works:**
- In Chrome/Edge: audio is sent to Google/Microsoft servers for processing (per their privacy policy)
- In Safari: processing is done on-device
- Audio is NOT sent to Zipgrid servers — it goes directly from the browser to the speech processing service
- Transcribed text is what Zipgrid receives — never the audio

**GDPR note:** Community voice posting should be covered in the Privacy Policy as: "When you use voice input, your speech is processed by your browser's built-in speech recognition service (Google or Apple, depending on your browser). Zipgrid only receives the transcribed text — never your audio." User consent is captured at first use.

**For premium accuracy (Phase 2 optional):** OpenAI Whisper API at ~$0.006 per minute. A 30-second community post costs £0.003. At 10,000 voice posts/month: £30/month. Negligible.
