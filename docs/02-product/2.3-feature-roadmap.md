# Feature Roadmap — 4-Phase Leapfrog Plan
## Zipgrid — UK EV Charging Platform

| Field | Value |
|-------|-------|
| **Version** | 1.0 — Complete build — all 4 phases implemented |
| **Last Updated** | September 29, 2026 |

---

## Roadmap Philosophy

> "Don't build what incumbents have. Build what they cannot build."

Every feature decision is filtered through the leapfrog lens:
- Does it extend the **voice-first** advantage?
- Does it deepen the **agentic AI** layer?
- Does it grow the **P2P marketplace network**?
- Does it serve **homeowners or SMBs** better than any competitor?

- ✅ PostgreSQL + PostGIS — 14 migration files, full schema
- ✅ GitHub Actions CI/CD — 4 workflows (web, ocpp, ai-service, deploy)
- ✅ Sentry error monitoring — instrumentation.ts, Node + Edge runtime
- ✅ Redis caching layer — session data, rate limiting, OCPP presence (ioredis)
- 🔧 Secret management — env vars defined; AWS Secrets Manager optional in prod
- 🔧 Supabase Realtime — client installed; polling used for session updates (upgrade path clear)

### 🔐 Authentication & Identity
- ✅ Email + password signup/login (`AuthService`)
- ✅ Google OAuth (`/api/v1/auth/oauth/google`)
- ✅ Apple Sign-In (`/api/v1/auth/oauth/apple`)
- ✅ Email verification (OTP via Resend)
- ✅ Password reset (token + confirm endpoint)
- ✅ JWT session management (Edge middleware, 15min access / 30d refresh)
- ✅ Role-based access control (driver / host / admin)
- ✅ KYC identity verification (Stripe Identity — `KycService` + `/api/v1/auth/kyc` + completion page)
- 🔧 Phone verification (Twilio — code complete; TWILIO_* env vars needed in prod)

### 🎙️ Voice System — Core
- ✅ Web Speech API integration (`VoiceService.ts`)
- ✅ OpenAI Whisper fallback (`POST /agent/transcribe`)
- ✅ GPT-4o intent parsing (`IntentParser` — 9 intents)
- ✅ Text-to-speech response (Web Speech Synthesis)
- ✅ Voice commands: find charger, book, session status, stop charging, spend query
- ✅ Host voice commands: earnings, block availability, session status
- ✅ Voice command fallback — unknown intent returns text suggestions
- ✅ Voice-guided onboarding wizard (`/host/onboarding` — 8-step with TTS hints)
- ✅ "Hey Zipgrid" wake word (`/api/v1/voice/wake` + `core/wake_word.py`)
- ✅ Floating `VoiceButton` component — integrates into all authenticated layouts

### 🤖 Agentic AI — Core
- ✅ LangChain `ZipgridAgent` — standard / hybrid / agentic modes, GPT-4o
- ✅ RAG knowledge base (`RAGPipeline` — Pinecone/in-memory)
- ✅ Fault detection → host notification (`FaultDiagnosisWorker`)
- ✅ Short-term session memory (Redis, 10 turns, 1hr TTL)
- ✅ Safety guard — PII scrub, confidence gate, rate limiting
- ✅ Tariff-aware auto-scheduling tool (`schedule_charging_tool`)
- ✅ Low battery alert tool (`low_battery_alert_tool`)
- ✅ Long-term user preferences (`user_preferences` table — migration 014)

### 🔌 OCPP Service — Core
- ✅ Node.js WebSocket OCPP 1.6J Central System
- ✅ Inbound: BootNotification, Heartbeat, StatusNotification, StartTransaction, StopTransaction, MeterValues, Authorize, DataTransfer
- ✅ Outbound: RemoteStart, RemoteStop, ChangeAvailability, SetChargingProfile, ClearChargingProfile, Reset, UnlockConnector, **ChangeConfiguration**
- ✅ Redis-backed connection presence (ioredis, TTL 90s, multi-replica safe)
- ✅ ChangeConfiguration push on first pairing (7 Zipgrid defaults)
- ✅ OCPP event log API (`/api/v1/chargers/[id]/events`)
- ✅ Device pairing API (`/api/v1/chargers/pair`)

### 👤 Host — Core

### 🚗 Driver — Core

### 💳 Payments — Core

## Parking Lot (Explicitly Out of Scope)

- NFT / tokenised host rewards
- Subscription for drivers (monthly flat fee for N sessions)
- Zipgrid-branded OCPP charger (own hardware)
- Social features (share a session, community leaderboard — gamification covers this)
- Dynamic tariff display inside charger hardware screen
