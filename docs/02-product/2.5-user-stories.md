# User Stories Catalogue
## Zipgrid — EV Journey Ecosystem Platform

| Field | Value |
|-------|-------|
| **Version** | 0.1 |
| **Last Updated** | September 24, 2026 |
| **Format** | As a [role], I want to [action] so that [benefit] |
| **Story Count** | 520 stories across 12 modules |

---

## Story Conventions

**Priority:**
- 🔴 P1 — Must Have (MVP blocker)
- 🟡 P2 — Should Have (Phase 2)
- 🟢 P3 — Could Have (Phase 3+)

**Acceptance criteria** are written as bullet points under each story where detail is needed.

**Roles used:**
- `Driver` — EV owner booking and paying for charging
- `Host` — Residential or commercial charger owner
- `Fleet Manager` — Corporate EV fleet administrator
- `Business Host` — SMB/commercial host with multiple chargers
- `Installer` — OZEV-certified marketplace technician
- `Admin` — Internal Zipgrid platform operator
- `Guest` — Unauthenticated user browsing the platform
