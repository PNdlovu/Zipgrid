## 1. Why Three Modes

Not every user wants AI running their charger. A retired homeowner may want to approve every scheduling decision. A fleet manager with 50 vehicles needs everything automated. A café owner wants suggestions but keeps final control over pricing.

Three modes give every user the exact level of control they are comfortable with — and lets them change it any time.

```
STANDARD (SaaS)          HYBRID                    AGENTIC
──────────────────        ─────────────────────     ──────────────────────
You control everything.   AI suggests.              AI acts.
AI answers questions.     You confirm.              You review outcomes.
No automation.            Best of both.             Maximum convenience.

→ Casual users            → Most users (default)    → Power users / fleets
→ Control-oriented        → Trust-building stage    → Fully hands-off
→ Free tier               → Smart/Growth tier       → Pro/Fleet tier
```

## 2. Mode Definitions

### Mode 1 — Standard (SaaS)

The user is in full control. The AI is a passive assistant — it answers questions and provides information, but never takes any autonomous action.

**What AI does in Standard mode:**
- Answers questions via chat/voice
- Provides information from knowledge base
- Shows pricing comparisons
- Shows session history
- Explains bills and earnings

**What AI does NOT do in Standard mode:**
- Schedules charging automatically
- Adjusts pricing automatically
- Books installers automatically
- Plans trips automatically
- Sends any notifications autonomously

**Best for:** Homeowners who are new to the platform and want to understand before trusting. Occasional drivers. Users who just want a map and booking tool.

---

### Mode 2 — Hybrid (Default)

The AI proactively surfaces suggestions and takes low-stakes actions automatically, but asks for confirmation before any action involving money, access, or scheduling changes.

**What AI does automatically (no confirmation needed):**
- Sends session reminders (15 min before booking)
- Notifies when charging is complete
- Warns about idle fees
- Detects charger faults and notifies host
- Shows cheaper tariff windows as a suggestion

**What AI suggests and asks to confirm:**
- Pricing adjustment: *"Your listing earns below average. Raise to £0.34/kWh? [Yes / Not now]"*
- Tariff scheduling: *"Cheap rate starts at 1am. Charge then? [Yes / No]"*
- Installer booking: *"Fault detected. Book nearest engineer? [Yes / Remind me later]"*
- Trip stop suggestion: *"You'll need charging before Manchester. Book Earlsfield first? [Yes / Show options]"*

**Best for:** The majority of users. Homeowners who want smart suggestions but keep final control. SMB owners who want AI pricing hints. Commuter drivers.

---

### Mode 3 — Agentic

Full automation. The AI acts on the user's behalf within defined boundaries set at onboarding. The user reviews outcomes, not decisions.

**What AI does automatically without confirmation:**
- Schedules all EV charging at cheapest tariff window
- Adjusts listing prices based on demand patterns
- Books a maintenance engineer when fault detected and confirmed in advance
- Plans and books all charging stops for a trip when destination is entered
- Sends payout notifications and earnings summaries
- Re-schedules a charging session if a time slot fills up
- Applies peak pricing during demand spikes
- Triggers emergency charging mode if battery drops below threshold while driving

**Boundaries set at Agentic onboarding (user defines these once):**
```
Maximum spend per session: £[X]
Minimum charger rating: [X] stars
Maximum price per kWh to accept: £[X]
Preferred charging time window: [X]pm – [X]am
Auto-book installers for: [ ] faults only  [ ] faults + maintenance
Trip planning: [ ] auto-book all stops  [ ] suggest only
Pricing auto-adjust: [ ] enabled  [ ] disabled
Monthly spend cap: £[X]
```

**What Agentic mode NEVER does without explicit one-time confirmation:**
- Charges more than the stated session maximum
- Books a session longer than the user's stated maximum
- Changes payout bank account
- Cancels an existing confirmed booking
- Sends a message to another user

**Best for:** Fleet managers, frequent commuters with recurring routes, homeowners with consistent availability schedules, power users who trust the platform.

## 3. Mode Selection UX

### At Onboarding

During registration (Step 5 of the onboarding flow), users see a simple three-card selector:

```
┌──────────────────────────────────────────────────────────────────┐
│  How much would you like Zipgrid to do for you?                  │
│                                                                  │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐             │
│  │   Manual    │  │   Hybrid    │  │   Agentic   │             │
│  │             │  │  ★ Default  │  │             │             │
│  │ I'll manage │  │ AI suggests │  │ AI handles  │             │
│  │ everything  │  │ I confirm   │  │ everything  │             │
│  │ myself      │  │             │  │             │             │
│  │             │  │ Recommended │  │ Pro feature │             │
│  └─────────────┘  └─────────────┘  └─────────────┘             │
│                                                                  │
│  You can change this at any time in Settings.                    │
└──────────────────────────────────────────────────────────────────┘
```

Plain-English descriptions — no technical jargon. The word "AI" is used sparingly. Users see **what the mode does for them**, not how it works.

### Switching Modes

Users can switch mode at any time from Settings → Your Zipgrid Mode.

When switching to Agentic:
1. Show what will be automated (plain-English list)
2. Set boundaries (spending caps, preferences)
3. Confirm with: *"Got it. Zipgrid will handle this for you. You can pause or change this any time."*

When switching from Agentic to Standard:
1. *"All automatic actions will stop. Any scheduled sessions will remain — only future automation stops."*
2. Confirm

## 4. Mode Indicators in UI

The user's current mode is always visible — subtly, in the profile or settings menu. Never hidden.

```
Profile icon (top right) shows:
  Standard:  No indicator (default, minimal)
  Hybrid:    Small ✦ sparkle indicator (AI active, not intrusive)
  Agentic:   Small ⚡ bolt indicator (fully automated)
```

In the AI assistant chat:
- Standard: *"Ask me anything — I'll answer."*
- Hybrid: *"I'm watching for opportunities to save you money. Just confirm when I ask."*
- Agentic: *"I'm handling things. Here's what I did today: [summary]"*

## 5. Mode × Subscription Tier Mapping

| Mode | Available On | Notes |
|------|-------------|-------|
| Standard | Free, Smart, All SMB tiers | Always available |
| Hybrid | Smart (homeowner), Starter+ (SMB) | Default for paying users |
| Agentic | Smart Annual, Growth+, Pro, Fleet | Full Agentic requires higher tier |

Agentic is a premium differentiator — it's the core of the value proposition for power users and the clearest reason to upgrade from free.

## 6. Agentic Mode — Data Model

```typescript
/**
 * @file domains/ai-voice/types.ts
 * @description Agentic mode user preferences stored per user.
 */
type AgentMode = 'standard' | 'hybrid' | 'agentic'

type AgenticBoundaries = {
  maxSpendPerSessionPence:    number        // e.g. 1000 (£10)
  minChargerRating:           number        // e.g. 4.0
  maxPricePerKwhPence:        number        // e.g. 45
  preferredChargingWindowStart: string     // e.g. '23:00'
  preferredChargingWindowEnd:   string     // e.g. '06:00'
  autoBookInstaller:          'faults_only' | 'faults_and_maintenance' | 'never'
  tripPlanningMode:           'auto_book' | 'suggest_only' | 'off'
  pricingAutoAdjust:          boolean
  monthlySpendCapPence:       number | null
}
```

## 7. Language Guide for Each Mode

The voice and AI assistant adapts its language to the user's mode.

| Scenario | Standard | Hybrid | Agentic |
|----------|---------|--------|---------|
| Cheap tariff detected | *"The cheap rate starts at 1am"* | *"Shall I schedule your charging for 1am?"* | *"I've scheduled your car to charge at 1am — you'll save £1.20"* |
| Charger fault | *"Your charger has an issue: GroundFailure"* | *"Your charger has a fault. Want me to book an engineer?"* | *"Fault detected. I've booked Andy's EV Installs for tomorrow 10am. Cost: £85."* |
| Trip to Manchester | *"Here are chargers along your route"* | *"I found two charging stops. Want me to book them?"* | *"Your trip is ready. Two stops booked: Coventry at 11am, then Manchester at 2pm."* |
| Pricing opportunity | *"Nearby listings charge £0.36/kWh"* | *"You're below market rate. Raise to £0.34/kWh?"* | *"I've raised your price to £0.34/kWh — in line with local demand. You'll earn £18 more this week."* |
