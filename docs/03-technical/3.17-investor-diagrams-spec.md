### Category D — Data Movement Diagrams

#### D1 — GDPR Data Flow
Shows: what PII is collected → where it is stored → how long → right to erasure path

#### D2 — Payment Escrow Flow
Shows: driver card → Stripe hold → session completes → capture → platform fee → host payout

#### D3 — OCPP Session Telemetry Flow
Shows: charger → MeterValues OCPP message → Central System → Redis pub/sub → Supabase Realtime → driver app WebSocket

#### D4 — AI Agent Request Flow
Shows: user utterance → Web Speech API → Orchestrator → Specialist Agent → Tool call → DB/OCPP/Stripe → Response → TTS

#### D5 — Referral Redemption Flow
Shows: referrer shares link → referee signs up → qualifying action completed → reward triggered → Wallet credit applied
