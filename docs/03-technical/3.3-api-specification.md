# API Specification
## Zipgrid — REST API v1

| Field | Value |
|-------|-------|
| **Version** | 0.1 |
| **Base URL** | `https://api.zipgrid.co.uk/v1` |
| **Protocol** | HTTPS only (TLS 1.3) |
| **Auth** | Bearer JWT on all protected routes |
| **Format** | JSON request/response bodies |
| **Last Updated** | September 24, 2026 |

---

## 1. Conventions

### Request Format
```
Content-Type: application/json
Authorization: Bearer <access_token>
Accept-Language: en-GB
```

### Response Envelope
Every response — success or error — uses this structure:
```json
{
  "success": true,
  "data": { ... },
  "error": null,
  "meta": {
    "page": 1,
    "pageSize": 20,
    "total": 142,
    "requestId": "req_01J2X..."
  }
}
```

### Error Response
```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "LISTING_NOT_FOUND",
    "message": "No active listing found with that ID.",
    "field": null,
    "docs": "https://docs.zipgrid.co.uk/errors/LISTING_NOT_FOUND"
  }
}
```

### HTTP Status Codes

| Code | Meaning |
|------|---------|
| 200 | Success |
| 201 | Created |
| 204 | No content (delete/logout) |
| 400 | Bad request / validation error |
| 401 | Unauthenticated |
| 403 | Forbidden (insufficient permissions) |
| 404 | Not found |
| 409 | Conflict (e.g. double-booking) |
| 422 | Unprocessable entity |
| 429 | Rate limit exceeded |
| 500 | Internal server error |

### Rate Limiting
```
X-RateLimit-Limit: 100
X-RateLimit-Remaining: 87
X-RateLimit-Reset: 1727200000
```
Default: 100 requests/minute per authenticated user. Geo-search: 30 requests/minute.

### Pagination
```
GET /v1/listings?page=2&pageSize=20
```
All list endpoints support `page` (1-indexed) and `pageSize` (max 100).

## 2. Authentication

### POST `/auth/register`
Register a new user account.

**Request**
```json
{
  "email": "sarah.chen@example.com",
  "password": "Str0ng!Pass",
  "fullName": "Sarah Chen",
  "phone": "+447911123456",
  "roles": ["driver", "host"]
}
```

**Response 201**
```json
{
  "success": true,
  "data": {
    "userId": "uuid",
    "email": "sarah.chen@example.com",
    "emailVerified": false,
    "accessToken": "eyJ...",
    "refreshToken": "eyJ...",
    "expiresIn": 900
  }
}
```

**Errors:** `EMAIL_ALREADY_EXISTS` · `INVALID_PASSWORD_FORMAT` · `INVALID_PHONE`

---

### POST `/auth/login`
**Request**
```json
{
  "email": "sarah.chen@example.com",
  "password": "Str0ng!Pass"
}
```

**Response 200**
```json
{
  "success": true,
  "data": {
    "userId": "uuid",
    "accessToken": "eyJ...",
    "refreshToken": "eyJ...",
    "expiresIn": 900,
    "roles": ["driver", "host"],
    "kycStatus": "verified"
  }
}
```

**Errors:** `INVALID_CREDENTIALS` · `ACCOUNT_SUSPENDED` · `EMAIL_NOT_VERIFIED`

---

### POST `/auth/refresh`
**Request**
```json
{ "refreshToken": "eyJ..." }
```
**Response 200** — new `accessToken` + `refreshToken` pair.

---

### POST `/auth/logout`
Invalidates the refresh token. **Response 204.**

---

### POST `/auth/verify-email`
```json
{ "token": "abc123def456" }
```
**Response 200** — `{ "emailVerified": true }`

---

### POST `/auth/request-password-reset`
```json
{ "email": "sarah.chen@example.com" }
```
**Response 200** — always succeeds (no email enumeration). Sends reset email if account exists.

---

### POST `/auth/reset-password`
```json
{
  "token": "reset-token-from-email",

}
```

---

### POST `/auth/verify-phone`

| `lng` | float | ✅ | Driver longitude |

KNN — returns the 5 closest active listings regardless of radius.

**Query Params:** `lat`, `lng` (both required). Optional: `plugTypes`.

**Response 200** — same shape as `/listings`, max 5 results.

### GET `/listings/route`
Corridor search for road-trip charging.

**Query Parameters**

| Param | Type | Description |
|-------|------|-------------|

| `corridorMetres` | int | Search width each side of route (default: 10000) |
| `plugTypes` | string[] | Optional filter |

**Response 200** — listings ordered by `routeProgressPct` (0=start, 1=end).
