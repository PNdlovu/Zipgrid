## 1. Onboarding Philosophy

Host onboarding is the highest-stakes funnel in Zipgrid. A host who completes setup and receives their first booking is retained at > 85%. A host who drops off before publishing earns nothing and never comes back.

Every step is designed around three principles:
- **Fastest possible path to the first payout**
- **Voice-guided wherever possible** — host may be in a driveway or garage, not at a desk
- **Trust signals at every friction point** — insurance confirmation, earnings preview, and support contact reduce anxiety

**Target:** 60% of hosts who start onboarding complete it within 24 hours.

## 2. Onboarding Flow — Residential Host

### Step 1 — Registration (2 minutes)

1. Host downloads app or visits zipgrid.co.uk
2. Signs up with Google / Apple / email
3. Selects role: "I want to share my charger and earn money"
4. Email verification (auto-sent; deep link opens app)

**Voice onboarding available from this step:**
> *"Welcome to Zipgrid. I'll walk you through setting up your charger listing. It takes about 5 minutes. First — what type of charger do you have? For example, EO, Ohme, Zappi, or another brand?"*

---

### Step 2 — Charger Setup (3 minutes)

**2a. Charger type selection**

Host selects their charger brand from a visual grid:
```
[EO Charging]  [Rolec EV]  [Andersen EV]
[Ohme]         [Zappi]     [Wallbox]
[Other smart]  [Non-smart (outlet only)]
```

**2b. OCPP pairing (smart charger)**

```
OCPP Pairing Wizard:
─────────────────────────────────────────
1. "On your charger, go to Settings → Connectivity → OCPP"
   [Brand-specific screenshot or short video shown]

2. Enter this URL in your charger's OCPP Server field:
   wss://ocpp.zipgrid.co.uk/1.6/[YOUR-CHARGER-ID]

3. Enter these credentials:
   Username: [generated chargePointId]
   Password: [generated apiKey]
   [Copy buttons for both fields]

4. Save settings on your charger and tap "Test Connection" here

5. [Connection test result]
   ✅ Connected — your charger is live!
   ❌ Not connecting — [troubleshooting tips link]
```

**Supported OCPP pairing guides (one per brand, with screenshots):**
- EO Charging: Settings → Wi-Fi & Connectivity → OCPP
- Rolec: Admin portal → OCPP Settings
- Andersen A2: Andersen app → Settings → Advanced → OCPP
- Ohme: Ohme app → Settings → Third-party integrations → OCPP
- Zappi: myenergi hub → Settings → OCPP Central System URL
- Wallbox: myWallbox portal → Device Settings → OCPP

**Non-smart charger path:**
> "Your charger doesn't have OCPP, so we'll use manual confirmation mode. You'll get a notification when a driver arrives and can confirm the session manually. You'll still see earnings but won't have real-time kWh data."

**2c. Configuration push** (smart charger only)

Once connected, platform automatically sends `ChangeConfiguration`:
- `MeterValueSampleInterval` = 60
- `HeartbeatInterval` = 300
- `StopTransactionOnEVSideDisconnect` = true
- `AuthorizeRemoteTxRequests` = true

### Step 3 — Listing Builder (5 minutes)

**3a. Location**

Map view with GPS "Place pin here" button. Host either:
- Uses GPS auto-detect (most common — they're standing in the driveway)
- Types address manually

Voice: *"I've placed a pin at 14 Garratt Lane, Earlsfield. Is that right?"*

**3b. Charger specs confirmation**

Pre-filled from OCPP BootNotification data where available (brand, model, firmware). Host confirms or corrects:
- Plug types supported (shown as icons: Type 2 / CCS / NACS / etc.)
- Max power (kW) — pulled from charger specs database
- Number of ports

**3c. Photos**

> "Add at least 1 photo of your charger and parking space. This is the biggest factor in your first booking."

Photo upload: tap to take with camera or choose from gallery. Platform shows a guide: "Cover photo tips — show the charger, the space it's in, and nearby landmarks."

Minimum: 1 photo. Recommended: 3–5.

**3d. Access instructions**

```
Access type: [Always open / Gate code / Buzz in / App unlock]

If gate code:
"Enter the code drivers will need to access your charger:"
[Code field]

"These instructions are encrypted and only shown to drivers after they've booked."
```

**3e. Amenities checklist**

Quick tap-to-select grid:
```
[✓ Wi-Fi available]  [✓ Covered/garage]  [ Toilets nearby]
[ Lighting]          [ EV parking only]  [ Wheelchair OK]
```

## 5. OCPP Pairing Troubleshooting Guide

### Charger Not Connecting After Setup

| Symptom | Likely Cause | Resolution |
|---------|-------------|-----------|
| "Connection timed out" | Wrong URL format | Ensure URL starts with `wss://` not `ws://` or `http://` |
| "Authentication failed" | Wrong credentials | Re-copy chargePointId and apiKey — check for spaces |
| "Charger shows offline" after pairing | Firewall blocking port 443 | Corporate/SMB firewalls may block WSS — IT team must open outbound port 443 |
| Charger connects but disconnects every 5 min | HeartbeatInterval too short | Check charger's heartbeat setting; set to 300 seconds |
| Zappi not connecting | Solar divert mode conflict | Disable solar divert temporarily during OCPP setup |

### Testing the Connection

Once paired, host can trigger a test from the app:
```
Listing → Charger Settings → Test Connection
  → Sends TriggerMessage: BootNotification to charger
  → Charger responds → "Connection confirmed ✅"
  → Last seen: just now
```
