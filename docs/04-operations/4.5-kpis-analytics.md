## 1. Metric Philosophy

Zipgrid tracks metrics at three levels:

1. **North Star Metrics** — the 2–3 numbers that best capture overall platform health
2. **Operational KPIs** — tracked daily/weekly to manage the business
3. **Leading Indicators** — early signals that predict future North Star movement

> **North Star:** Monthly Charging Sessions — the one number that captures both sides of the marketplace working simultaneously (supply active + demand converting).

## 8. Dashboard Specifications

### 8.1 Executive Dashboard (Founder / Leadership)
**Refresh:** Daily
**Source:** Supabase views + PostHog

Panels:
- GMV (month to date vs. last month)
- ARR trajectory chart (12 months)
- Active listings count + WoW growth
- Active drivers count + WoW growth
- Sessions this month + projection to month end
- Platform NPS (latest score + trend)
- EBITDA (month to date)

---

### 8.2 Growth Dashboard (Product / Marketing)
**Refresh:** Daily
**Source:** PostHog + Supabase

Panels:
- New signups by day (hosts vs. drivers)
- Onboarding funnel (host: 8 steps + driver: 4 steps)
- First booking conversion rate (7-day + 14-day)
- Cohort retention heatmap (drivers: months 1–12)
- Voice adoption rate trend
- Top listing cities by session volume
- Search → booking conversion funnel
- CAC by acquisition channel

---

### 8.3 Host Dashboard (Self-serve — in app)
**Refresh:** Real-time for session data, daily for earnings
**Source:** DB (host-scoped RLS)

Panels:
- Earnings this month (£) + trend
- Sessions this month + WoW change
- Utilisation rate per listing
- Next payout (amount + date)
- Listing performance table (kWh, sessions, revenue per listing)
- AI suggestion if under-performing: "Your listing earns less than average — here's why"
- Recent reviews

---

### 8.4 SMB Analytics Dashboard
**Refresh:** Daily
**Source:** DB (host-scoped)

Panels:
- Revenue per charger (bar chart, last 30 days)
- Utilisation rate heatmap (hour of day × day of week)
- Peak hours bar chart
- Dwell time average (session duration after charging completes)
- Unique driver count
- Customer return rate (% of drivers who booked more than once)
- Dynamic pricing recommendation widget

---

### 8.5 Operations Dashboard (Internal)
**Refresh:** Real-time
**Source:** Supabase + OCPP service metrics

Panels:
- Live active sessions (count + map view)
- OCPP charger health (online/offline/faulted count)
- Active disputes queue (count + oldest unresolved)
- Pending KYC reviews
- Stripe: payment success rate (last 1 hour)
- Redis memory and hit rate
- API error rate (last 15 minutes)
- Incident reports opened today

## 9. Alerting Rules

| Alert | Condition | Notify | Channel |
|-------|-----------|--------|---------|
| New P1 incident report | Severity = Critical | Ops + Founder | PagerDuty |
| Insurance claim triggered | Claim auto-created | Ops | Slack #trust-safety |
| Charger offline > 2 hours during booking window | Status offline + listing active | Host (push) + Ops | Push + Slack |
| Listing rating drops below 4.0 | Rolling 10-review avg < 4.0 | Ops | Slack #ops |
| Host earnings below £10 for 2 consecutive weeks | DB query | Growth team | Slack #growth |
| Booking cancellation rate for a listing > 20% | 7-day rolling | Ops | Slack #trust-safety |
| Daily sessions down > 30% vs. 7-day avg | PostHog alert | Ops + Growth | Slack #alerts |
| ARR growth rate < 5% MoM | Finance review | Founder | Email weekly |
| Dispute older than 5 business days unresolved | DB query daily | Ops | Slack #ops |
| API error rate > 1% | Vercel monitoring | On-call | PagerDuty |
