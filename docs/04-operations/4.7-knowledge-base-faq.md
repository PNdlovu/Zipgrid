## 1. Architecture Overview

```
User has a question
        │
        ├── Types in search box (help centre)
        │         │
        │         ▼
        │   Semantic search (RAG over KB vectors)
        │   + Intercom Articles full-text search
        │         │
        │         ▼
        │   Ranked article list → user reads → resolved
        │
        ├── Asks AI assistant (in-app chat or voice)
        │         │
        │         ▼
        │   AI pulls relevant KB chunks via RAG
        │   + user's session context
        │         │
        │         ▼
        │   Personalised answer in natural language
        │
        └── Browses by category
                  │
                  ▼
            Category → Sub-category → Article
```

## 3. AI-Powered Search

### 3.1 Semantic Search Architecture

Standard full-text search (keyword matching) fails when users phrase questions naturally:
- User types: "my car stopped charging but I'm still connected"
- Full-text search: finds articles with "stopped charging" but misses the best article "Session stuck — cable connected but no power"
- Semantic search: understands the intent, surfaces the right article

```python
# knowledge_base/search.py
"""
@file search.py
@description Semantic search over Zipgrid knowledge base.
Uses OpenAI embeddings to match user query intent to article content.
Combines semantic similarity with keyword boosting for best results.
"""

async def search_knowledge_base(query: str, user_role: str, limit: int = 5) -> list[Article]:
    """
    Semantic search with role-based filtering.
    Drivers don't see host-only articles and vice versa.
    """
    # 1. Embed the query
    query_embedding = await openai.embeddings.create(
        model="text-embedding-3-small",
        input=sanitise_user_input(query, max_length=500)
    )

    # 2. Search Pinecone for similar article chunks
    results = pinecone_index.query(
        vector=query_embedding.data[0].embedding,
        filter={"roles": {"$in": [user_role, "all"]}},
        top_k=limit * 2,  # over-fetch, then re-rank
        include_metadata=True
    )

    # 3. Re-rank by combining semantic score + recency + helpfulness rating
    ranked = rerank(results, query)

    return ranked[:limit]
```

### 5.1 Article Indexing Pipeline

When an article is published or updated:

```python
# cms/indexer.py
"""
@file indexer.py
@description Indexes KB articles into Pinecone for RAG retrieval.
Called on article publish/update via webhook from Intercom CMS.
"""

async def index_article(article: Article) -> None:
    """Chunk article, embed, and upsert to Pinecone."""
    chunks = chunk_article(article.content, chunk_size=400, overlap=50)

    embeddings = await openai.embeddings.create(
        model="text-embedding-3-small",
        input=[c.text for c in chunks]
    )

    vectors = [
        {
            "id": f"{article.id}-chunk-{i}",
            "values": embedding.embedding,
            "metadata": {
                "article_id":   article.id,
                "article_title": article.title,
                "category":     article.category,
                "roles":        article.applicable_roles,  # ['driver', 'host', 'all']
                "last_updated": article.updated_at.isoformat(),
                "chunk_text":   chunk.text,
            }
        }
        for i, (chunk, embedding) in enumerate(zip(chunks, embeddings.data))
    ]

    pinecone_index.upsert(vectors=vectors, namespace="knowledge-base")
```
