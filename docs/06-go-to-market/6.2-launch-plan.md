## Phase 1 — MVP Build (Months 1–6)

### Goal: Ship a working P2P + voice + smart scheduling platform.

### Sprint Structure
6-week build cycles with weekly internal demos.

| Sprint | Weeks | Focus |
|--------|-------|-------|
| Sprint 1 | W1–W2 | Auth, DB schema, OCPP service skeleton, CI/CD |
| Sprint 2 | W3–W4 | OCPP device pairing (EO + Rolec), host listing builder |
| Sprint 3 | W5–W6 | Driver map search (PostGIS), listing detail, booking flow |
| Sprint 4 | W7–W8 | Stripe payments, session management, real-time kWh |
| Sprint 5 | W9–W10 | Voice system (Web Speech + Whisper + GPT-4o intent) |
| Sprint 6 | W11–W12 | Agentic AI core (tariff scheduling + fault detection) |
| Sprint 7 | W13–W14 | Reviews, notifications, incident reports, host earnings |
| Sprint 8 | W15–W16 | Additional charger brands (Andersen, Ohme, Zappi, Wallbox) |
| Sprint 9 | W17–W18 | Admin panel, moderation tools, audit log UI |
| Sprint 10 | W19–W20 | QA, security audit, performance testing, App Store submission |
| Sprint 11 | W21–W22 | Beta testing (50 hosts + 100 drivers), bug fixes |
| Sprint 12 | W23–W24 | Launch preparation, press materials, waitlist email |

### Phase 1 Exit Criteria (Launch Gate)
All of the following must be true before London public launch:

- [ ] ≥ 300 active charger listings live in London
- [ ] All 6 OCPP brands paired and tested end-to-end
- [ ] Voice commands working for all 12 core intents (6 driver + 6 host)
- [ ] Agentic tariff scheduling running in production (Octopus Agile integrated)
- [ ] Stripe payouts completing successfully in staging (end-to-end test)
- [ ] Security review passed (no critical or high vulnerabilities)
- [ ] GDPR privacy policy published; cookie consent live
- [ ] Platform insurance policy placed and active
- [ ] App Store (iOS) + Play Store (Android) approved
- [ ] p95 map search latency < 200ms under simulated load
- [ ] Zero data loss in OCPP MeterValues over 48hr soak test
- [ ] Incident response runbook written and team trained
- [ ] 50-user beta completed with NPS ≥ 40

## Risk Register

| Risk | Probability | Impact | Mitigation |
|------|-------------|--------|------------|
| Insurance not placed before launch | Medium | 🔴 Launch blocker | Engage broker in Month -3; have backup underwriter identified |
| OCPP brand refuses integration | Low | 🟡 Medium | OCPP is open standard; legal obligation for OCPP-compliant devices |
| App Store rejection | Medium | 🟡 Delays launch 2 weeks | Submit 4 weeks early; have demo device for Apple review |
| Funding delayed | Medium | 🔴 Blocks hiring | Keep burn low; founder-led build to MVP |
| Key engineer departure | Low | 🟡 Sprint delays | Document architecture thoroughly; no single points of failure |
| Safety incident at launch | Low | 🔴 Brand damage | Insurance in place; incident protocol trained; rapid response plan ready |
| Pod Point launches P2P before us | Low | 🟡 Competitive | Accelerate supply acquisition; lock in installer channel exclusivity |
| Stripe KYC delays for hosts | Medium | 🟡 Payout delays | Communicate expected timeline; manual review escalation path |
